# vehicle-co2-prediction
Vehicle CO₂ Emissions Prediction
Description

This project focuses on predicting vehicle CO₂ emissions using Machine Learning.

The project uses a Random Forest model to estimate CO₂ emissions based on vehicle characteristics such as engine size, transmission, fuel type, and fuel consumption.

The analysis and model development are presented in the Jupyter Notebook included in this repository.

Objectives

The main objectives of this project are to:

Explore and understand vehicle data.
Analyze the factors influencing CO₂ emissions.
Prepare and preprocess the dataset.
Train a Machine Learning model.
Evaluate the model's performance.
Predict CO₂ emissions for vehicles based on their characteristics.
Dataset

The dataset contains information about different vehicles and their characteristics, including:

Vehicle make
Vehicle model
Vehicle class
Engine size
Transmission
Fuel type
Fuel consumption
CO₂ emissions

The target variable is:

CO₂ emissions (g/km)

Machine Learning Model

The project uses a Random Forest Regressor to predict vehicle CO₂ emissions.

Random Forest was selected because it is well suited to regression problems involving multiple numerical and categorical features and can capture nonlinear relationships between vehicle characteristics and CO₂ emissions.
